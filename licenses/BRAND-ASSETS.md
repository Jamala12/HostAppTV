# HostAppTV brand assets

The TV launcher banner is a VectorDrawable generated by `tools/generate-banner.py` from the bundled Gelasio font, licensed under the [SIL Open Font License 1.1](Gelasio-OFL.txt). Install fontTools in an isolated Python environment to regenerate it.

The asymmetric outline and sage play mark use the app's existing code-native emblem and palette. The wordmark is baked into vector outlines so the launcher does not depend on installed fonts. The 16:9 canvas preserves the TV banner shape at any display resolution.
